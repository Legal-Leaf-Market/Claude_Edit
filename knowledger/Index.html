KLR03: post journal entries to Sage via KnowLedger

Submits finished JEs to KnowLedger's "Post Transactions to Target" flow on the Decisions platform; KnowLedger's connector makes the Sage hop from its own allowlisted IP. Nothing here talks to Sage's gateway, so GW-0011 is out of the picture by construction.

Measure first

Diagnostics reach the portal and prove auth against a flow id that cannot exist, so nothing can execute. The probe is the one pre-push call that touches the real flow: it sends an empty transaction list with SendToGL forced false and says so on its face.

Settings (writes Script Properties; secrets stay there, never in code)

Blank fields are left unchanged. Type __CLEAR__ to delete a stored value. Values are trimmed on save and on read; an invisible pasted space has caused a fake outage before.

Load and validate

Paste straight from Excel (tab separated, header row first) or a JSON array of line objects. Columns bind by header name; JE, Date, GL (or a combined Coding column), and Debit/Credit (or a signed Amount) are required. A "Coding" column like 1001||Kerry Fam|Fiag-3115|taxable splits into GL, Department, Entity, SubAccount, Class.
