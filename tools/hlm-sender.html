Follower outreach for herbal_leaf_market

Two touches, not a blast. The welcome is three short messages when someone new follows. The newsletter is one message about a week later carrying that week's pick. Anyone who says no is muted here and never appears in a batch again.

Worth keeping in mind
  • Firing the same message at dozens of accounts in one sitting is the pattern Instagram's spam heuristics watch for, and the usual result is a temporary messaging block. Ten to fifteen a session is the sane ceiling.
  • Scripted sending is against Instagram's terms, which prohibit automated interaction. Your account carries that risk.
  • Hemp is a US offer, and a follower list collects accounts that are nowhere near the US. Someone who cannot legally order is a mute, not a send.
  • One "no thanks" is the whole conversation. Mute them the moment it arrives, before the next batch.

3. Open the tabs

How to get the whole batch per click instead of one

Click "Open batch" once. Chrome opens one tab, blocks the rest, and puts a blocked-pop-ups icon at the right hand end of the address bar. Click that icon, allow pop-ups and redirects for this page, then click "Open batch" again. The blocked ones were never lost, they are still queued. If Chrome will not keep that setting for a local file, the one-at-a-time path needs no setting at all.

Opening someone's tab stamps them as contacted for the current campaign, because that is the only signal this page gets. If you open a tab and do not actually send, click the state chip on their row to clear it.

What a queued tab does on its own

A bookmarklet cannot launch itself, and no page can inject script into another site's tab: that is a browser boundary, not a missing feature. So anything past "arm it with one click" needs the userscript, which the browser runs on every matching page by itself. Install that and a queued tab arms with no click at all.

The loop uses ONE Instagram tab and points it at each account in turn, so only the very first one is a pop-up and the rest are ordinary navigations. That is deliberate: reopening a tab per account needs pop-up permission that Chrome often will not keep for a page opened from a file, and this way it needs none. Untick this to be left on the last thread instead.

Both carry the SAVED messages and the saved pick, so save first and then re-drag or re-download. Each build is stamped with a revision number, and a newer revision from this page replaces whatever the browser was holding, which is what makes a change here actually reach the tab. On a DM tab, click the bookmark once: a panel appears top right and the hotkeys go live for that tab.

  • Alt + Shift + W sends the three welcome messages, opening the dialog first if it is not open yet.
  • Alt + Shift + D only opens the message dialog, and sends nothing.
  • Alt + Shift + N sends the one newsletter message.
  • Alt + Shift + 1 / 2 / 3 sends a single welcome message.
  • Esc cancels an unattended run if one is counting down, and otherwise hides the panel.
  • Alt + Shift + I still works as an alias for the welcome run.

On a profile, opening the dialog means clicking that profile's own Message button, so the thread can only be with the account whose page it is. On a DM tab it means searching for the handle and taking an exact match or nothing. Either way you never have to open the dialog by hand.

The bookmarklet needs one click per tab, and that is a browser rule rather than a choice: a javascript: URL cannot be opened by a script and no page can inject into another site's tab. The userscript, in Violentmonkey or Tampermonkey, is run by the browser on every matching page, which is why it is the one that can do the whole loop unattended.

The panel has its own edit box with its own Save, for a one-off tweak on the machine you are sitting at. That save is real and survives reloads and other tabs, and this page overrides it only when you save a new revision here.
